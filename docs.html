curl
brew
npm
$ curl -fsSL shellmate.dev/install | sh

Quick start

Three commands from install to your first answer.

  1. Run it inside a repoNavigate to any git repository and run shellmate. It indexes the working tree on first launch.
  2. Ask a questionTry shellmate ask "what does this function do" pointed at any file.
  3. Review before anything runsAny suggested shell command shows its full effect and waits for y/N before executing.

Model providers

Shellmate ships with a local model by default. Swap in any API-compatible provider by setting provider in your config. Your code is only sent off-device if you choose a remote one — local stays fully offline.

Uninstalling

One command, no residue.

$ shellmate uninstall

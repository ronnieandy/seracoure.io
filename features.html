features

Six commands. Click one to see it run.

Every Shellmate command is a small, single-purpose script — same philosophy as the Unix tools it sits next to.

-rwxr-xr-x · 4.1k explain.sh Explain any file or function in plain language, with surrounding context already factored in.
-rwxr-xr-x · 2.8k fix-error.sh Paste a stack trace, get the failing line and a reviewed patch as a diff.
-rwxr-xr-x · 6.4k review-pr.sh Reviews your current branch against main before you open the PR.
-rw-r--r-- · 1.2k recall.log Remembers project conventions across sessions.
-rwxr-xr-x · 3.7k run-safe.sh Shows exactly what a command will do, then waits for confirmation.
drwxr-xr-x · — plugins/ Extend it with your own commands in any language.
